## 6. How to regenerate

From project root:

```r
# Full stock-group re-knit + appendix build (slow: includes Nephrops/JABBA)
source("report/finalise/00_run_all.R")
runAll(render = TRUE, formats = "html")

# Reuse existing HTML; restage figures, QA, takeaways, PDF
runAll(render = FALSE)
```

Individual notebooks can be knit via the RStudio knit button or `report/knit_to_report.R`.
Starting stocks are shipped in `inst/extdata/`; refreshing them from local assessments
is a maintainer-only step (not part of the GitHub virgin path).

Mackerel illustrations: knit `06_mackerel_projections.Rmd` (requires `pel-om.RData` from 01); refresh Beamer mackerel panels via `05_figs.Rmd`.
